The brief

KOA needed a platform its insurance agents could use to manage customers and policies, with less manual work, and a public website to bring in clients and new agents.

What we built

We built the platform from scratch: the public website, the agent portal, and the backend behind them, including KOA's insurance workflows and integrations.

Where it is now

KOA is running a live pilot. We support the platform on a retainer that covers maintenance, bug fixes, new features, infrastructure and deployment.

The work

Members of our team have contributed code to Open Chat Studio, Dimagi’s open-source chatbot platform. We also self-host it and run ZEYA on it.

How we built ZEYA on it

ZEYA’s pipeline is generated from code, not set up by hand. Danger signs are checked by fixed rules before any AI runs, and 307 tests run those rules the way the platform runs them. Before each release, a check compares the live pipeline with the code.

Why it matters for clients

It is the same way we work on client systems: the risky parts are written in code, tested, and checked before they go live.
